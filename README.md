# speedtest.py — замер скорости интернета

Скрипт десять раз подряд скачивает файл по указанному адресу, засекая каждое скачивание целиком, и печатает среднее время запроса, объём скачанного и скорость канала.

## Требования

Python 3.9 или новее, больше ничего: скрипт работает на стандартной библиотеке, устанавливать нечего. Проверялось на Python 3.12 в Linux.

## Запуск

```
python3 speedtest.py <адрес>
```

Адрес — прямая ссылка на файл, например на тяжёлую картинку:

```
python3 speedtest.py "https://images.unsplash.com/photo-1506744038136-46273834b3fb?w=4000&q=100"
```

Кавычки нужны, когда в адресе есть `&`, иначе командная оболочка обрежет адрес на первом же амперсанде.

Строка на каждый запрос показывает ход замера, три нижние строки — итог.

## Что именно измеряется

Время запроса считается от отправки запроса до последнего принятого байта, то есть включает установку соединения и TLS-рукопожатие — ровно то, что человек ощущает как «сколько скачивался файл». Среднее время — сумма десяти замеров, делённая на десять.

Объём считается по фактически принятым байтам, а не по заголовку `Content-Length`. Скрипт представляется своим `User-Agent` и не просит сжатие, поэтому по сети идёт файл как есть и объём совпадает с размером файла, умноженным на десять.

Скорость — весь скачанный объём, делённый на суммарное время. Задание просит «мб/с», и это читается двояко, поэтому печатаются обе величины: мегабайты в секунду и мегабиты в секунду. Мегабайт здесь — 10⁶ байт, как принято считать скорость канала у провайдеров.

## Если что-то пошло не так

Скрипт печатает одну строку и возвращает код 1:

```
$ python3 speedtest.py
Укажите адрес: python3 speedtest.py https://example.com/image.jpg

$ python3 speedtest.py example.com
Адрес должен начинаться с http:// или https://

$ python3 speedtest.py http://127.0.0.1:9/x.jpg
Запрос 1: не удалось соединиться — [Errno 111] Connection refused

$ python3 speedtest.py https://upload.wikimedia.org/wikipedia/commons/f/ff/Pizigani_1367_Chart_10MB.jpg
Запрос 3: сервер ответил 429 Too many requests
```

Серия обрывается на первой же ошибке и называет номер неудавшегося запроса: средняя скорость по части серии описывала бы не канал, а момент отказа.

Последний случай — обычная реакция крупных хранилищ на десять быстрых скачиваний подряд. Wikimedia, например, отдаёт 429 уже на третьем запросе, а Python без своего `User-Agent` получает от неё 403. Если выбранный адрес режет частые запросы, возьмите файл с другого хоста.
