# tt-ad-robot — тестовое задание: замер скорости интернета

Чтение на старте: @docs/PROTOCOL.md @docs/RULES.md @docs/DESCRIPTION.md

## Суть проекта

Скрипт меряет скорость канала: десять последовательных скачиваний файла по адресу из аргумента, на выходе — среднее время запроса, суммарный объём и скорость. Сдача — публичный репозиторий на GitHub с инструкцией запуска. Текст задания дословно — `docs/DESCRIPTION.md`.

## Правила поведения

Один шаг очереди задачи за сессию, завершение сессии — по `docs/PROTOCOL.md`.

## Жёсткие ограничения

Python 3 и только стандартная библиотека: проверяющий запускает скрипт без установки зависимостей.

Очередь шагов в таск-файле правит пользователь; сессия, увидевшая нужду в новом шаге, пишет предложение в «Контекст».

## Грабли

Хранилище Wikimedia (`upload.wikimedia.org`) отвечает 403 на `User-Agent: Python-urllib/…` и 429 на третьем скачивании подряд — для десяти запросов подряд не годится. Отсюда собственный `User-Agent` в скрипте; прогоны и пример в README идут по картинке Unsplash из записи журнала за 2026-09-21.

## Точки входа

`speedtest.py` — сам замерятель, появится на первом шаге задачи.

`docs/tasks/speedtest.md` — очередь шагов и текущий контекст.
