# speedtest — замерятель скорости интернета

## Постановка

Цель: скрипт и README лежат в публичном репозитории на GitHub, ссылку можно отправить работодателю, по README запуск воспроизводится с чистого клона.

- [x] Замер. `speedtest.py` принимает адрес аргументом, делает десять последовательных запросов, каждый дочитывает ответ до конца, и печатает среднее время запроса, суммарный объём скачанного и скорость в МБ/с и Мбит/с.
      Проверка: `python3 speedtest.py <адрес тяжёлой картинки>` печатает все четыре величины, объём совпадает с размером файла, умноженным на десять, скорость того же порядка, что реальная скорость канала.
- [x] Поведение на ошибках. Запуск без аргумента, недоступный хост, ответ не 200 — короткое сообщение и ненулевой код возврата вместо трейсбека.
      Проверка: `python3 speedtest.py; echo $?` и `python3 speedtest.py http://127.0.0.1:9/x.jpg; echo $?` — оба печатают сообщение одной строкой и код 1 или 2.
- [x] Инструкция. `README.md`: что скрипт делает, что нужно для запуска, команда запуска, пример вывода, пояснение про единицы измерения.
      Проверка: клон в пустой каталог, запуск строго по README, вывод похож на пример.
- [x] Публикация. Репозиторий на GitHub через `gh repo create`, первый push, ссылка записана в «Контекст».
      Проверка: `gh repo view --web` открывает репозиторий, README отрисован.

Блокер: если выбранный адрес отдаёт ответ без заявленной длины или с редиректами так, что объём не сходится с размером файла, или если способ проверки шага разошёлся с реальностью — описать расхождение в «Блокере» и остановиться.
