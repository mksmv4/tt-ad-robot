# Правила

## Конвенции кода

Python 3, стандартная библиотека, один файл скрипта, запуск `python3 speedtest.py <url>`.

Комментарии — назывной формой: `# разбор аргументов`, не `# разберём аргументы`.

## Конвенции работы

Проверка шага — прогоном: в «Контекст» или журнал идёт команда и её реальный вывод.

Доки — часть того же коммита, что и код шага.

Сообщение коммита — Conventional Commits с русским описанием в одну строку: `feat(scope): …`, `fix(scope): …`, `docs: …`, `chore: …`, `test: …`. Описание — суть шага, рассуждение остаётся в журнале.
