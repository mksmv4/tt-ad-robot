# Спецификация

## Цели

Тестовое задание, текст дословно:

> Написать скрипт-замерятель скорости интернета со своего компьютера.
>
> Он должен принимать адрес, куда стучаться (какая-нибудь тяжелая картинка), запускать последовательно 10 запросов к этому адресу, дожидаться ответа, вычислять среднее время запроса, объем скачанных данных и печатать в консоли скорость мб/с.
>
> Ответ залить на github и дать репозиторий с инструкциями.

Сдача — ссылка на публичный репозиторий на GitHub, по README которого проверяющий запускает скрипт у себя.

## Стек

Python 3.12 (`/usr/bin/python3`), только стандартная библиотека: запуск без установки зависимостей.

GitHub CLI `gh`, аккаунт `mksmv4`, git-операции по ssh — для создания репозитория и публикации.

## Ключевые решения

Единицы вывода: «мб/с» из задания читается и как мегабайты, и как мегабиты, поэтому печатаются обе величины — МБ/с и Мбит/с.
