# Протокол

## Протокол сессии

**Старт:** автозагрузка хаба (`CLAUDE.md` → `AGENTS.md` → «Чтение на старте») → таск-файл `docs/tasks/<задача>.md`. Больше на старте ничего не читается.

**Работа:** за сессию — не больше одного шага из очереди «Постановки»; критерии шага записаны там же. Шаг бывает больше сессии: «Контекст» несёт точку продолжения, следующая сессия ведёт тот же шаг дальше. Чекбокс шага ставится по критерию завершения, не по числу сессий.

**Завершение:**

1. результат — в артефакт задачи (код, README, спека);
2. таск-файл: статус в шапке актуален, чекбокс шага по критерию завершения, «Контекст» перезаписан целиком;
3. грабли сессии — сразу в постоянный дом: `AGENTS.md` § Грабли или `RULES.md`;
4. `JOURNAL.md` — запись сверху с заголовком `## <ISO-дата> — суть работы`, если сделана осмысленная работа; рассуждение — что решили и почему — живёт здесь;
5. коммит — всё сделанное сессией, включая правки доков; сообщение — одна строка с именем шага, рассуждение остаётся в журнале.

## Таск-файл

Задача — файл `docs/tasks/<задача>.md`: постановка, перезаписываемый контекст, шапка со статусом первой строкой.

```
статус: в работе | блокер | готово
```

Шаблон:

```markdown
статус: в работе

# <задача>

## Постановка
<цель; очередь шагов чекбоксами `- [ ]`, по одному на шаг; способ проверки
завершения шага; критерий блокера. Пишется при создании задачи, живёт
до её конца.>

## Контекст
<перезаписывается каждой сессией целиком: следующий шаг и файл, с которого
начать; хвосты; состояние среды и незакоммиченные правки>

## Блокер
<секция есть только при статусе «блокер»: вопрос пользователю, что уже
выяснено, предлагаемое решение; при статусе «в работе» сессия стирает
секцию на первом же завершении>
```

Цель и способ проверки меняет только пользователь. Цель, разошедшаяся с реальностью, и способ проверки, разошедшийся с реальностью, — блокер: сессия пишет в «Блокер», что разошлось и что предлагает, и ставит статус «блокер». Блокер снимает пользователь: правит «Постановку» или «Контекст» и возвращает статус «в работе».

«Контекст» перезаписывается, история живёт в журнале.

## Статус «готово»

Все чекбоксы очереди закрыты — сессия ставит «готово». Сделанное пользователь проверяет руками по журналу.

## Порядок на месте

Грабля уходит в постоянный дом в той сессии, где нашлась: у неё максимум контекста о находке. Перед записью факта — поиск существующей записи о том же; найдена → обновляется она, второе место ссылается на первое.
